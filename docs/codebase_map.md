This document provides a comprehensive map of the Rollodex project codebase. It details the purpose and contents of major directories and files, including:
*   Root-level configuration and asset directories (`assets/`, `__mocks__/`).
*   Core application logic in `components/`, `hooks/`, `lib/`, and `providers/`.
*   The main application structure within `app/`, organized using Expo Router with route groups like `(auth)`, `(tabs)` (covering features like Community, Discover, Housing, Profile, Provider, Rewards, Wallet), `(agreements)`, and other screen-specific directories (`chat/`, `profile/` for other users, etc.).
*   TypeScript `types/`.
*   Supabase backend integration, noting the primary configuration likely under `home/project/supabase/` with its migrations, and a standard (but possibly unused) `supabase/` directory at the project root.
*   An empty `utils/` directory.

This map is intended to help developers understand the project's architecture, locate key features, and identify relationships between different parts of the codebase.
